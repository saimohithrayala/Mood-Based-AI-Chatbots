# Mood-Based-AI-Chatbots
An intelligent AI chatbot system that changes its personality, tone, and response style based on the mood selected by the user. This project demonstrates dynamic conversational AI behavior using multiple emotion-driven chatbot modes such as Angry, Sad, Funny, and more.

#Project Overview
This project is designed to create a more engaging and personalized AI conversation experience by allowing users to interact with chatbots that respond according to specific emotional personalities.Instead of a single generic AI assistant, the system provides multiple mood-based AI agents that generate responses with unique tones, expressions, and conversational behaviors.

#Features
🎭 Multiple AI personalities
⚡ Energetic chatbot mode
😢 Sad/emotional chatbot mode
😂 Funny/comedic chatbot mode
🧠 Dynamic response generation
💬 Real-time conversational interface
🔄 Easy mood switching
🌐 Scalable architecture for adding new moods
📱 User-friendly UI
🤖 AI-powered conversational engine
